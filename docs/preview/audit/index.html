“A button with no name” — my mistake, not the book's

I reported the ask button as unlabelled and said there was no argument against fixing it. There is: it sits inside aria-hidden="true" with tabindex="-1". It is a deliberate second copy of the shield, put a thumb's reach away for whoever has scrolled, and a screen reader never reaches it — the nameplate's own shield is the one read out. My agent did not look at its ancestors. It does now, and the finding is gone. Nothing to build.
