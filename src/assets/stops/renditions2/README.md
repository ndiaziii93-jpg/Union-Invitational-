# Playful and sporty: the second nine

The first nine read as club heraldry — handsome and far too solemn for a
virtual stop played alone on a cold Saturday. These three directions are
built for a game rather than a ceremony, with the pine and cream kept as a
base and the accents let off the leash.

* **d-** The sports card. Bubble-gum trading card: diagonal colour blocks,
  fat halftone, speed stripes, the ball coming out of the frame.
* **e-** The mascot. A cartoon golf ball with a face and a different mood a
  month: bobble hat, frozen solid, lovestruck. Needs the character pushed
  right before use — at the moment the headline crosses its face.
* **f-** The arcade cabinet. Retro game art, on the nose for competitions
  that are actually played virtually: a glowing fairway grid running to a
  banded pixel sun, a dotted flight arc, scanlines.

1600 × 898 WebP, no lettering anywhere. Full-resolution originals are in
the commissioner's Blueprint Studio library.
