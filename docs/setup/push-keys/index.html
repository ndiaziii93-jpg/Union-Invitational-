Notification keys

For the commissioner, once. This makes the pair of keys that lets the book send chat notifications. They are made here, in this browser, and go nowhere else until you paste them into Supabase.

Nothing leaves this page. There is no server behind it: the keys are made by your browser’s own cryptography and shown below. Don’t send the private key to anyone, including in a chat.

This browser can’t make them. Try Safari or Chrome.

VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY

Then, in Supabase

  1. Open your project → Edge Functions → Secrets.
  2. Add a secret named VAPID_PUBLIC_KEY and paste the first key.
  3. Add a secret named VAPID_PRIVATE_KEY and paste the second.
  4. Save. Once they are saved, close this page; making new keys later would switch everybody’s notifications off until they turn them on again.
